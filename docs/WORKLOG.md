## Batch 1 — chat (2026-10-21) · 11.3% → 16.5%

Built and verified:
- Message queue: send while the agent works; queued turns run in order; edit, remove,
  run now (interrupts), pause/resume, clear. One project runs one build at a time,
  enforced in `claimNext` (a running build blocks its project).
- Stop: cancel flag polled by the worker, aborts the in-flight model request; spent
  tokens are charged; partial work kept in the draft.
- Plan mode (read-only tools, structured plan, Approve and build), Ask mode leaves
  drafts alone, clarifying-questions tool + card, task list tool + panel, memorize tool.
- Attachments (images/PDF/text as model content blocks, `save_attachment` tool),
  smart paste, @ file mentions, slash commands, intent chips, + menu, tips, emoji icon,
  browser notifications.
- Message actions: copy, copy link, feedback, undo/reapply latest edit, bookmark,
  rerun; footer "Worked for · credits". History gains a Bookmarks tab.
- Editable code view (save = commit), soft delete + restore.

Bugs found and fixed along the way:
- Each build now answers its own message (previously "newest user message in the
  project", which a queue would have broken).
- Worker loop versioned on globalThis: one live loop, always on current code.
- DB pool: local PGlite needs a single connection (P2023 / dropped connections /
  empty session lookups under concurrency) and a short idle timeout.
- Read-only turns no longer open drafts; a turn that changes nothing removes an
  empty draft instead of leaving it stuck in BUILDING.
- `restoreTree` deletes files the restored commit doesn't contain.

Known gap: route handlers throw `Response` objects for auth failures, which Next turns
into 500s instead of 401/403/404.
